Privacy Policy - Property Management Automation

Last updated: September 25, 2026

Overview

Property Management Automation is a personal, single-user automation tool built and operated by Jason Chung for his own property management workflows. It is not a public product or service, and it is not made available to other users.

What this application accesses

This application requests access to the following Google account data, belonging solely to the developer's own Google account:

  • Gmail: to read tenant-related email threads, send automated notifications (welcome emails, rent reminders, inspection report notices), and manage drafts and labels related to property management correspondence.
  • Google Calendar: to create, read, and update calendar events related to rent reminders, move-in dates, and property maintenance schedules.
  • Google Drive: to read lease documents and tenant files stored in Drive, and to create, share, and organize property-related documents (such as move-in inspection reports).

It also accesses a personal Notion workspace (via a separate Notion integration, not part of this OAuth application) to read and update a private tenant-tracking database.

How this data is used

All accessed data is used exclusively to automate the developer's own property management tasks: tracking tenant move-ins, sending scheduled communications to the developer's own tenants, and organizing property-related documents. Processing happens locally on the developer's own computer and through Anthropic's Claude Code, used under the developer's own account.

Data sharing

This application does not share, sell, or transmit any accessed data to third parties. No data is used for advertising. No data is used to train machine learning models beyond the standard operation of the Claude Code assistant used to run this automation, under the developer's existing agreement with Anthropic.

Data retention

Data is retained only as long as needed to operate the automation (e.g., cached tenant records, sent-message logs) and is stored locally on the developer's own devices.

Security

Access credentials (OAuth tokens) are stored locally on the developer's own computer and are not transmitted to or stored by any third party beyond Google's own OAuth infrastructure.

Scope of use

This application is used by a single individual (the developer) for personal property management purposes only. It is not distributed to, or intended for use by, any other party.
